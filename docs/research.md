# Primary-source research and design rationale

Reviewed 2026-10-13. These sources inform the scoped implementation; they do not certify this baseline or endorse the project. No benchmark text is copied wholesale. Project-specific control weights, small scope, conservative unknown states and read-only defaults are authored design choices.

- [NIST SP 800-128, updated final](https://csrc.nist.gov/pubs/sp/800/128/upd1/final): security-focused configuration management provides context for approved baselines and monitoring configuration changes. This project illustrates selected practices, not complete federal compliance.
- [OpenBSD/OpenSSH sshd_config manual](https://man.openbsd.org/sshd_config): generally first obtained keyword values win; keywords are case-insensitive, arguments case-sensitive. Includes and Match blocks complicate interpretation. The lab refuses to guess their effective semantics. `prohibit-password` is not identical to disabling all direct root login.
- [Linux kernel sysctl documentation](https://docs.kernel.org/admin-guide/sysctl/kernel.html): `randomize_va_space=2` adds heap randomization to value-1 protections. Platform and legacy-application caveats motivate owner review rather than blind enforcement.
- [Microsoft Get-NetFirewallProfile](https://learn.microsoft.com/en-us/powershell/module/netsecurity/get-netfirewallprofile?view=windowsserver2025-ps): ActiveStore represents resultant applicable policy, unlike the default persistent store. The collector selects ActiveStore explicitly and does not claim to test packet filtering.
- [Microsoft Get-MpComputerStatus](https://learn.microsoft.com/en-us/powershell/module/defender/get-mpcomputerstatus?view=windowsserver2025-ps): read-only protection status includes RealTimeProtectionEnabled. Only that property is selected; scan history and private identifiers are not retained.
- [Microsoft Get-SmbServerConfiguration](https://learn.microsoft.com/en-us/powershell/module/smbshare/get-smbserverconfiguration?view=windowsserver2025-ps): read server configuration rather than executing a Set-* command. Server and client policy remain distinct.
- [Python SQLite documentation](https://docs.python.org/3.14/library/sqlite3.html): SQL values should be parameter-bound; a connection's transaction context is not a substitute for closing it. The exporter uses both explicit closing and transaction context.
- [GitHub secure Actions use](https://docs.github.com/en/actions/reference/security/secure-use): least-privilege tokens and full-SHA action pins reduce workflow risk. This repo does not use pull_request_target, deployment credentials or unchecked event content in shell commands.
- [GitHub standard hosted runner reference](https://docs.github.com/en/actions/reference/runners/github-hosted-runners): `macos-15-intel` is a supported standard public-repository runner. An ARM64 capacity-acquisition failure prompted selection of that explicit pool; no tests were disabled and no paid/larger runner was selected.
- Official pinned scanners: [Gitleaks](https://github.com/gitleaks/gitleaks), [Trivy](https://github.com/aquasecurity/trivy), [actionlint](https://github.com/rhysd/actionlint). Archive digests/versions live in tools.lock.json; findings are not suppressed to pass CI.

Inference from these sources: an effective assurance demonstration should bind checks to a reviewed baseline, show provenance/unknowns, separate policy changes from host drift and leave risky remediation to an approved workflow. That inference—not a standards requirement—is the architecture chosen here.
