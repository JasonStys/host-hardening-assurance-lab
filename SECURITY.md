# Security reporting and responsible use

Use this lab only with synthetic data or explicit permission from a system owner. No host changes, exploit payloads, remote scanning, credential collection or automatic remediation are implemented.

For a suspected vulnerability, contact [Jason Stys via LinkedIn](https://www.linkedin.com/in/jason-stys-31b30b351/) to arrange a private report. Do not place secrets, production configurations or personal information in public issues. Include a minimal synthetic reproducer and relevant version/commit, not live data.

Read the [threat model and limitations](docs/security.md). A passing check does not certify security. The owner must assess operational compatibility, alternate controls, stale evidence and approved deviations.
